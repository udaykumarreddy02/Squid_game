📌 Project Overview

The **Squid Game Twitter Analytics Dashboard** is an interactive Power BI project that analyzes Twitter conversations related to the Netflix series *Squid Game*. The dashboard provides insights into user engagement, tweet activity, follower distribution, retweets, locations, and social media trends using interactive visualizations and KPIs.

This project demonstrates the use of Business Intelligence techniques to transform raw Twitter data into meaningful insights for social media analysis and audience engagement.

---

## 🎯 Project Objectives

- Analyze Twitter activity related to Squid Game.
- Measure user engagement through tweets and retweets.
- Identify top influencers and followers.
- Analyze tweet trends over time.
- Explore tweet distribution by year and quarter.
- Build an interactive dashboard for social media analytics.
